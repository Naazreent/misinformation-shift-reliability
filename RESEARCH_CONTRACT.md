# Research contract

## Study title

**Reliability of Misinformation Classification under Source Shift**

## Question

How much does a random record-level split overestimate text-classification
performance relative to a publisher/source-disjoint split on the supplied IFND
dataset after normalized-duplicate controls?

## Prespecified hypotheses

- **H1:** Text classifiers will have higher macro-F1 on the random stratified
  split than on the source-disjoint split.
- **H2:** A source-only classifier will perform very strongly on the random
  split but fail to transfer to unseen sources.
- **H3:** Probability calibration will degrade on the source-disjoint test set,
  reflected in higher Brier score, log loss, or expected calibration error.

These hypotheses were prespecified before the repeated-seed matrix. Results are
reported descriptively because three seeds do not provide strong inferential
power.

## Contribution boundary

Version 0.2 is a dataset, evaluation, and controlled model reconstruction. It
does not claim a new model, objective truth classification, state-of-the-art
performance, statistical significance, or safe deployment. The original
FNN/CNN/LSTM/BERT values remain legacy claims; only results generated by this
repository are treated as verified.

## Data contract

- Required columns: `id`, `Statement`, `Web`, `Category`, `Date`, `Label`.
- Raw input is immutable and checked against the recorded SHA-256.
- Labels are converted explicitly from boolean or accepted binary strings.
- Statements are normalized with Unicode NFKC, lower-casing, and collapsed
  non-word whitespace only for duplicate grouping; models receive original text.
- All normalized-text groups with conflicting labels are excluded.
- One record is retained from each remaining normalized-text group.
- The exact retained IDs and split assignments are saved per run.
- The identified source is the Kaggle IFND data card. Its licence field was
  `Unknown` when checked, so raw data is not redistributed.

## Split protocols

1. `random_stratified`: 70% train, 15% validation, 15% test, fixed seed.
2. `source_disjoint`: publisher/source groups are disjoint across train,
   validation, and test; deterministic candidate selection preserves both
   labels and records the selected sources.

Temporal evaluation is deferred because the CSV contains 11,321 missing dates
and an implausible 2025 date cluster that must be traced to source formatting.

## Models and fixed budget

- Majority-class dummy classifier.
- Source-only one-hot logistic regression as a confounding diagnostic.
- TF-IDF (1-2 grams) plus class-balanced logistic regression as the classical
  text baseline.
- FNN: train-only learned token embeddings, mean pooling, a 128-unit hidden
  layer, ReLU, and dropout 0.3.
- CNN: train-only learned token embeddings and 100 filters for each of kernel
  widths 3, 4, and 5, followed by max pooling and dropout 0.5.
- LSTM: train-only learned token embeddings and a two-layer, 128-unit LSTM with
  dropout 0.3.
- BERT-tiny: `google/bert_uncased_L-2_H-128_A-2`, pinned at revision
  `30b0a37ccaaa32f332884b96992754e246e48c5f` and fine-tuned with a new binary
  classification head. This is not `bert-base-uncased`.

All neural models use weighted cross-entropy, deterministic PyTorch execution,
validation-only checkpoint selection, and fixed budgets. No hyperparameter
search is performed. The word models run for at most five epochs with patience
two; BERT-tiny runs for three epochs.

## Metrics

- Primary: test macro-F1.
- Secondary: accuracy, balanced accuracy, macro precision, macro recall,
  weighted F1, Brier score, log loss, expected calibration error, and confusion
  matrix counts.
- Validation metrics are reported separately and are never substituted for the
  test result.

## Repetition and uncertainty

The verified reconstruction uses prespecified seeds 13, 42, and 87. Reported
tables use mean ± sample standard deviation. Source-disjoint candidate searches
use non-overlapping seed blocks, producing three distinct publisher holdouts.
The protocol-gap table pairs results by seed, but because the selected test
examples differ between protocols, its differences are descriptive rather than
a formal paired significance test. A manuscript-strength extension should add
more source holdouts and source-clustered uncertainty intervals.

## Acceptance criteria

- Dataset checksum and schema validation pass.
- Unit tests and synthetic smoke test pass.
- No normalized statement or source crosses a disjoint split boundary.
- Every result is traceable to a run ID, data checksum, resolved configuration,
  prediction file, and metric record.
- Headline tables regenerate from machine-readable artifacts.
- Unsupported legacy dissertation values are not presented as reproduced.
- Every stored aggregate contains exactly three seeds per model, metric, and
  protocol; duplicate model/protocol/seed/metric rows fail aggregation.
